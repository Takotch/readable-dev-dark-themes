# Readable Dev Dark Themes
A dark theme setting with a color scheme that makes text easy to read and the use of icons.

# Target Applications
* PowerShell (using Oh My Posh)
* Eclipse IDE (for Japanese Language Environment)
* ...More will be added later!

# Required Fonts
* [Nerd Fonts](https://www.nerdfonts.com/)
* [UDEV Gothic](https://github.com/yuru7/udev-gothic)

# Notes
This is a shared version of the theme created and used by Takotch.
Depending on your environment, some color combinations may be hard to read. Please adjust them as needed.
